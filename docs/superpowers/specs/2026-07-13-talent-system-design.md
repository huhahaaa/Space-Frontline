# 天赋系统 — 局外成长

**日期**: 2026-07-13
**状态**: 设计完成，待实现

---

## 概述

在主菜单新增天赋系统入口，提供局外永久成长（meta-progression）。六边形网格布局，通关后根据血量评级获得天赋点，用于解锁天赋节点。与局内 buff 系统互补不重叠。

---

## 资源循环

### 星级评价
- 通关后进入独立结算页，根据塔剩余血量评定星级：

| 血量条件 | 星级 | 获得天赋点 |
|----------|------|-----------|
| 满血（HP = 100%） | ⭐⭐⭐ | 3 |
| 半血及以上（HP ≥ 50%） | ⭐⭐ | 2 |
| 半血以下（HP < 50%） | ⭐ | 1 |
| 失败 | 无 | 0 |

- **差额规则**：同一关卡只有达成更高评价时，才能从该关获得差额天赋点。例如：
  - 首次 1 星通关 → 获得 1 点
  - 再次 2 星通关 → 获得 1 点（差额 2-1）
  - 再次 3 星通关 → 获得 1 点（差额 3-2）
- 每关最高累计获得 3 点

### 天赋点余额
- 持久化存储于 `SharedPreferences`
- 全局累计余额，不按关卡分桶
- 天赋页 UI 显示当前余额

## 天赋布局

### 网格结构
- **六边形网格**，节点为六边形 Tile
- **空中心环形起点**：中心位置无节点，6 个相邻位置环绕第一圈
- **12 格两圈**：
  - 第一圈 6 个（4 实心 + 2 空壳占位）
  - 第二圈外围 6 个（全部空壳占位）
- 总计 12 个节点位置

### 解锁规则
- 中心 6 个方向各有 1 个入口节点（第一圈）
- 解锁一个节点需要：**至少一个相邻节点已解锁**（或为中心相邻，中心视为虚拟已解锁）
- 第一圈节点（邻接中心）可直接解锁
- 第二圈节点需要对应方向的第一圈节点已解锁

### 升级方式
- **单节点单级**：每个天赋节点消耗 1 天赋点，点了即满，不可升级
- 空壳节点在 UI 上可见但标注"???"，点击提示"暂未开放"

## 天赋效果实现接口

每个天赋节点对应一个 `TalentId` 枚举值，效果通过 `TalentManager` 统一查询：

```dart
enum TalentId {
  reinforcedArmor,   // 加固装甲
  expandedChoices,   // 选择扩充
  expDrain,          // 经验汲取
  freeReroll,        // 重抽机会
}

class TalentManager {
  bool isUnlocked(TalentId id);
  int get availablePoints;
  bool unlock(TalentId id);       // 扣 1 点，返回是否成功
  // 查询效果
  int get bonusHp;
  int get buffChoiceCount;        // 3 或 4
  int get bonusExpPerWave;
  int get freeRerollsPerGame;
}
```

## 持久化

- **存储引擎**：`SharedPreferences`
- **Key 设计**：
  - `talent_points` → int，天赋点余额
  - `talent_unlocked` → String（逗号分隔的 TalentId 索引列表，如 `"0,1,3"`）
  - `level_stars_{levelId}` → int，每个关卡已达成的最高星级（0-3）
- **加载时机**：游戏启动时从 SharedPreferences 读取
- **保存时机**：结算页获得天赋点时立即写入

## UI 页面清单

### 1. 主菜单入口
- 主菜单新增 **"天赋"** 按钮（排在"开始游戏""怪物图鉴"之后）
- 点击进入天赋页

### 2. 天赋页
- 全屏页面，深色背景
- 六边形网格 Canvas 绘制（CustomPaint + CustomPainter）
- 顶部显示天赋点余额
- 点击已解锁节点 → 无反应（仅展示效果文字）
- 点击可解锁节点（邻接已解锁）→ 弹出确认弹窗（消耗 1 点）
- 点击空壳/不可达节点 → 提示"暂未开放"或"需先解锁相邻节点"
- 左上角返回按钮

### 3. 结算页
- 通关后 push 独立页面（替换当前游戏页）
- 展示：塔剩余血量、星级动画（逐星点亮）、击杀数、存活波数
- 展示获得天赋点数
- "返回主菜单"按钮
- 失败时不进入结算页（保持现有"防线失守"覆盖层）
- **不在结算页提供重玩按钮**——返回主菜单即可

## 六边形网格布局细节

```
         [R2] [R2]
       [R1] [R1] [R2]
     [R2] [中心] [R1] [R2]
       [R1] [R1] [R2]
         [R2] [R2]
```

- 中心为空（不可交互的视觉锚点）
- 第一圈 6 个六边形环绕中心（4 实心 + 2 空壳）
- 第二圈选取 6 个位置（每 2 个第一圈节点之间放 1 个），全部空壳
- 六边形尺寸：外接圆半径约 36px（适合手机屏宽）
- 选用 axial 坐标系 (`q, r`) 做位置计算和邻居查找

## 结算页与游戏页的跳转流程

```
游戏页 (GameScreen)
  ├─ gameWon = true → 延迟 1.5s → Navigator.pushReplacement → 结算页
  └─ gameOver = true → 保持现有覆盖层，点击返回主菜单
```

结算页不依赖 Flame 引擎，纯 Flutter Widget。
