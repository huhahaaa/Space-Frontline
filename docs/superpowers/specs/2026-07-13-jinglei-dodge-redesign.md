# 惊雷闪避重设计 — 弧线冲刺 + 残影 + 粒子拖尾

**日期**: 2026-07-13
**状态**: 设计完成，待实现

---

## 概述

将惊雷敌人当前纯横向位移闪避改为弧线冲刺 + 残影 + 粒子拖尾。提升视觉华丽度与流畅感。

---

## 闪避机制

### 触发条件（沿用现有逻辑）
- 子弹进入 120px 检测范围
- 预测最近距离 < 38px
- 不在冷却中
- 不被冻结/恐惧

### 冲刺参数
| 参数 | 值 | 说明 |
|------|-----|------|
| 持续时间 | 0.18 秒 | ~11 帧 @60fps |
| 路径 | 二次贝塞尔曲线 | 起点→控制点→终点 |
| 控制点偏移 | ~60px | 垂直子弹方向 |
| 终点偏移 | ~80px | 垂直子弹方向 |
| 速度曲线 | easeOut | 先快后慢 |
| 无敌 | 冲刺全程免疫伤害 | `takeDamage` 直接 return |
| 冷却 | **1.5 秒** | 冲刺结束后开始冷却 |

### 冷却规则
- 冲刺结束 → 冷却计时器 1.5s
- 冷却期间：**可受伤**，但**不触发新闪避**
- 冷却结束 → 恢复闪避能力

---

## 视觉效果

### 残影
- 冲刺期间每 0.04s 采样一次位置，存储最近 3 个采样
- 残影透明度：采样后 0→0.05s 淡入到 alpha 0.35，0.05→0.2s 淡出到 0
- 淡紫色混合：`Color.fromRGBO(180, 140, 255, alpha)`
- 渲染方式：惊雷 `render()` 中先画残影、再画本体（不创建额外 Component）
- 使用 `saveLayer` + `ColorFilter` 实现颜色混合

### 粒子拖尾
- 冲刺时每秒 emit ~30 个粒子
- 粒子方向：随机后向扇形 ±60°（远离冲刺方向）
- 颜色：淡紫→透明，`Gradient.radial` 无硬边柔光
- 大小：2–4px
- 存活：0.3 秒
- 数据结构：`_DodgeParticle { position, velocity, life, size }`
- 推进：`update()` 中移动 + 衰减，死粒子移除
- 渲染：`render()` 中统一绘制

### 冲刺本体
- 半透明紫色覆盖：`Color.fromRGBO(160, 120, 255, 0.25)`
- 缩放微弹：scale 1.0 → 1.15 → 1.0，0.1 秒内完成（增强发力感）

### 不需要的
- ~~冷却指示器~~ — 用户明确不需要

## 状态机

```
IDLE → (检测到威胁 && 不在冷却) → DODGING (0.18s 无敌冲刺)
DODGING → (0.18s 到期) → COOLDOWN (1.5s 可受伤不可闪避)
COOLDOWN → (1.5s 到期) → IDLE
```

冻结/恐惧时：无论状态，不触发新闪避。已在冲刺中则完成当前冲刺再进入冷却。
