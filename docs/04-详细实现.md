# 第四章 游戏详细设计与实现

## 4.1 项目创建与环境配置

### 4.1.1 创建 Flutter 项目

使用 Flutter CLI 创建项目：

```bash
flutter create defend_the_tower
```

### 4.1.2 添加 Flame 依赖

在 `pubspec.yaml` 中添加核心依赖：

```yaml
dependencies:
  flutter:
    sdk: flutter
  flame: ^1.26.1          # 2D 游戏引擎
  shared_preferences: ^2.2.0  # 本地持久化存储
  audioplayers: ^5.2.1    # 音频播放
```

### 4.1.3 配置资源目录

```yaml
flutter:
  assets:
    - assets/images/
    - assets/images/explosion/
    - assets/images/lightning_chain/
    - assets/images/lightning_strike/
    - assets/images/fire_storm/
    - assets/images/enemy-4/
    - assets/music/
```

### 4.1.4 初始化游戏入口

在 `main.dart` 中，将 Flame 的 `GameWidget` 嵌入 Flutter 页面：

```dart
void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await TalentManager.instance.init(); // 加载永久天赋
  runApp(const DefendTheTowerApp());
}
```

关键设计：**Flutter 负责 UI 菜单和 HUD 叠加层，Flame 负责游戏世界渲染**。两者通过 `GameWidget` 桥接，通过 `ValueNotifier<HudData>` 单向通信。

## 4.3 炮塔与无人机实现

### 4.3.1 炮塔（Tower）

炮塔位于屏幕底部中央（`size.y * 0.92`），核心功能是**自动瞄准最近敌人**和**计算炮管旋转角度**：

```dart
class Tower extends PositionComponent {
  double _aimAngle = -pi / 2; // 默认朝上

  void aimAtNearest(List<Enemy> enemies) {
    Enemy? nearest;
    double minDist = double.infinity;
    for (final e in enemies) {
      final d = e.position.distanceTo(position);
      // 检查是否在射击范围内
      if (d < minDist && _isInRange(e)) {
        minDist = d;
        nearest = e;
      }
    }
    if (nearest != null) {
      _aimAngle = (nearest.position - position).angleTo(Vector2(0, -1));
    }
  }
}
```

炮管在 `render()` 中使用 Canvas 绘制白色旋转矩形。

### 4.3.3 射击系统

```dart
void _fireBullets(double dt) {
  _fireTimer += dt;
  final interval = 0.5 * _fireRateMultiplier * (_overchargeActive ? 0.5 : 1.0);
  if (_fireTimer < interval) return;
  _fireTimer = 0;

  if (_towerTarget != null) {
    final dmg = 1.0 * _damageMultiplier * (_bloodRageActive ? 1.20 : 1.0);
    _launchBullet(dmg, _towerTarget!);

      _launchBullet(dmg, _towerTarget!, angleOffset: 0.13);
    }
  }
}
```

## 4.4 输入控制实现

### 4.4.1 触控输入

玩家输入通过以下方式处理：

- **道具槽点击**：Flutter Widget 层处理（`ItemBar` 的 `GestureDetector.onTap`），调用 `game.useItem(index)`
- **轨道打击瞄准**：Flame 的 `PointerMoveCallbacks` + `TapCallbacks` mixin：
  - `onPointerMove`：更新十字准星位置
  - `onTapDown`：确认目标，计算延迟后触发雷击伤害

```dart
// 轨道打击瞄准流程
void _enterAimingMode() {
  _aimingItem = ItemId.orbitalStrike;
  _crosshair = Crosshair();
  add(_crosshair!);
  _paused = true; // 暂停游戏等待瞄准
}

void _onAimConfirm(Vector2 target) {
  // 1.5s 延迟后，在目标位置造成 50 AoE 伤害（半径 80px）
  final strike = LightningStrike(
    position: target,
    onStrike: () {
      for (final e in enemies) {
        if (e.position.distanceTo(target) <= 80) {
          e.takeDamage(50);
        }
      }
    },
  );
  add(strike);
  _exitAimingMode();
}
```

### 4.4.2 防重复输入

- 道具使用后立即从库存移除，防止二次点击
- 轨道打击瞄准中禁止其他操作（`_paused = true`）
- Buff 选择后清空卡片列表，防止重复选择

## 4.5 敌人及 AI 行为实现

### 4.5.1 水银（普通敌人）— `Enemy`

最基础的敌人类型，直接向下移动：

```dart
class Enemy extends PositionComponent {
  static const double baseSpeed = 50.0;
  static const double baseHp = 3.0;

  @override
  void update(double dt) {
    super.update(dt);
    if (isFrozen) return; // 冻结：不移动
    if (isFeared) {
      position.y -= baseSpeed * speedMultiplier * dt; // 恐惧：反向移动
    } else {
      final slowFactor = isSlowed ? (1.0 - slowed!.factor) : 1.0;
      position.y += baseSpeed * slowFactor * speedMultiplier * speedFactor * dt;
    }
  }
}
```

### 4.5.2 沃土（精英敌人）— `EliteEnemy`

**两阶段行为**：

1. **下降阶段**：以 40px/s 速度移动至 `stopY`（屏幕中部 ≈ `size.y * 0.5`）
2. **驻守阶段**：停止移动，每 2.5s 释放震荡波，第 2 次震荡波后开始产怪

```dart
void _updateShockwave(double dt) {
  if (_shockwaveElapsed >= 0) {
    _shockwaveElapsed += dt;
    if (_shockwaveElapsed >= _shockwaveDuration) {
      _shockwaveElapsed = -1; // 震荡波结束
    }
  } else {
    _shockwaveTimer += dt;
    if (_shockwaveTimer >= _shockwaveInterval) {
      _emit(); // 释放震荡波
    }
  }
}

void _emit() {
  _shockwaveCount++;
  _shockwaveCenter = position.clone();
  _shockwaveElapsed = 0;
}
```

**震荡波渲染**：三层同心圆（填充 + 外描边 + 细描边），半径从 0 → `max(size) × 1.5`，透明度从高到低衰减。

### 4.5.3 护士（辅助敌人）— `NurseEnemy`

核心逻辑是 **每 2.5s 净化 + 治疗**：

```dart
List<({PositionComponent target, double amount})> purgeTick(
  Iterable<PositionComponent> allEnemies,
) {
  for (final e in allEnemies) {
    if (e is! Enemy && e is! EliteEnemy) continue;
    if (e.position.distanceTo(position) > purgeRadius) continue; // 100px

    // 净化：移除燃烧、感电、减速
    e.firstChild<Burning>()?.removeFromParent();
    e.firstChild<Shocked>()?.removeFromParent();
    e.firstChild<Slowed>()?.removeFromParent();
    e.add(PurgeProtected()); // 1s 免疫火焰风暴

    // 治疗：恢复已损失 HP 的 80%
    final missing = e.maxHp - e.hp;
    if (missing > 0.01) {
      e.hp += missing * 0.80;
    }
  }
}
```

**视觉**：护士本体渲染粉色径向渐变光晕（`Gradient.radial`），每次治疗触发时高亮脉冲（alpha 0.15 → 0.90，0.5s 衰减）。

### 4.5.4 惊雷（Boss 精英）— `JingLeiEnemy`

项目中最复杂的敌人 AI，实现两阶段系统：

**生成（`_spawnJingLei`）**：
```dart
void _spawnJingLei() {
  final center = Vector2(size.x / 2, 110); // 三角形中心
  final jingLei = JingLeiEnemy(hpMultiplier: _enemyHpBonus, speedMultiplier: _enemySpeedBonus);
  jingLei.position = center;

  // 3 个电池敌人，等边三角形（半径 90px）
  for (int i = 0; i < 3; i++) {
    final angle = -pi / 2 + i * 2 * pi / 3; // 从顶部顺时针
    final batteryPos = center + Vector2(cos(angle), sin(angle)) * 90;
    final battery = Enemy(hpMultiplier: _enemyHpBonus * 1.25, speedMultiplier: _enemySpeedBonus * 0.5);
    battery.position = batteryPos;
    battery.isBattery = true;
    // DrainLink 连接线
    add(DrainLink(fromRef: jingLei, toRef: battery));
  }

  // 回调：汲取时播放动画
  jingLei.onDrain = (pos) => add(DrainArrow(position: pos));
  jingLei.onBatteryDrained = (pos) => add(DeathExplosion(position: pos));
}
```

**汲取阶段（Phase 1）**：
- 每 1.0s 汲取下一个存活电池
- 电池被 `takeDamage(9999)` 秒杀 → 移除 → DrainLink 自动断开
- 3.0s 后全部电池死亡 → `_finalizeDrainPhase()`

**最终阶段（Phase 2）**：
- 根据汲取数（0-3）查表赋予属性
- 自适应子弹闪避（详见 6.2 创新点六）
- 闪避使用二次贝塞尔曲线 + 残影 + 粒子效果

**关键设计**：玩家击杀的电池不会被汲取（`_drainNextEnemy` 自动跳过已死亡电池），因此玩家可以通过集火电池削弱惊雷的最终形态。

## 4.6 碰撞检测实现

### 4.6.1 子弹与敌人碰撞

使用 Flame 的 AABB 矩形重叠检测：

```dart
void _checkCollisions() {
  for (final bullet in children.whereType<Projectile>()) {
    for (final enemy in _enemies) {
      if (enemy.isDead) continue;
      if (bullet.toRect().overlaps(enemy.toRect())) {
        // 命中处理
        _onBulletHitEnemy(bullet, enemy);
        break; // 普通子弹命中一次后消失
      }
    }
  }

  // 无人机子弹穿透处理
  for (final bullet in children.whereType<DroneBullet>()) {
    for (final enemy in _enemies) {
      if (bullet.hasHit(enemy)) continue; // 已命中过的跳过
      if (bullet.toRect().overlaps(enemy.toRect())) {
        _onDroneBulletHitEnemy(bullet, enemy);
      }
    }
  }
}
```

### 4.6.2 子弹与震荡波碰撞

震荡波使用**点与圆距离检测**：

```dart
bool _bulletHitsAnyShockwave(Vector2 point) {
  for (final elite in children.whereType<EliteEnemy>()) {
    if (elite.shockwaveActive && elite.isInsideShockwave(point)) {
      return true;
    }
  }
  return false;
}
```

### 4.6.3 命中处理流程

```
子弹命中敌人
  ├─ 连锁闪电：寻找最近 1-2 个目标，造成 0.6/1.0 固定伤害
  ├─ 灼热弹头：施加燃烧堆叠（1.0/1.6/2.5 DPS）
  ├─ 冰霜弹头：施加减速（30/50%）
  ├─ 分裂弹：生成 2-3 个 50% 伤害的子子弹
  ├─ 暗影标记：如存在，伤害乘以 1.4/1.6
  ├─ 扣除敌人 HP
  ├─ 命中闪光特效
  └─ 伤害数字飘字
```

### 4.6.4 避免重复碰撞

- 普通子弹命中后立即 `removeFromParent()`
- 无人机子弹维护 `Set<int> _hitEnemies`，用敌人 hashCode 去重
- 分裂子弹标记 `isSplit = true`，防止二次分裂

## 4.7 动画实现

### 4.7.1 序列帧动画

项目采用**预加载精灵表 + 手动帧切换**模式：

**EMP 冲击波**（16 帧，`emp.png` 2048×128）：
```dart
static Future<void> preload() async {
  final image = await Flame.images.load('emp.png');
  _frames = List.generate(16, (i) {
    return Sprite(image,
      srcPosition: Vector2(i * 128.0, 0),
      srcSize: Vector2(128, 128),
    );
  });
}
```

**死亡爆炸**（8 帧，独立 PNG）：
```dart
static Future<void> preload() async {
  _frames = [];
  for (int i = 1; i <= 8; i++) {
    _frames!.add(await Sprite.load('explosion/explosion-$i.png'));
  }
}
```

**动画帧更新**：每帧累加 `_elapsed`，`currentFrame = (_elapsed / frameTime).floor()`，达到总帧数后自移除。

### 4.7.2 精灵表动画

命中闪光（`HitFlash`）：12 帧 2×6 网格精灵表（`Hit_effect_01.png`），0.04s/帧，单次播放后自移除。

燃烧特效（`BurningEffect`）：12 帧循环火焰动画（`BurningEffect.png`），0.06s/帧，挂载为燃烧敌人的子组件。

### 4.7.3 程序化动画

以下动画通过代码实时计算而非预制帧：

| 动画 | 实现方式 |
|---|---|
| 炮管旋转 | `canvas.rotate(_aimAngle)`，每帧更新瞄准角度 |
| 护士光环 | `Gradient.radial` 径向渐变，alpha 随时间衰减 |
| 震荡波 | 三层同心圆，半径线性增长，alpha 线性衰减 |
| 闪电链锯齿 | 每帧随机生成锯齿路径顶点偏移 |
| 闪避残影 | 每 0.04s 采样当前位置和精灵，渲染半透明副本 |
| 闪避粒子 | 径向渐变圆，远离运动方向发射，带衰减 |
| 道具飞入 | 三阶段缓动：弹性弹出 → 曲线飞行 → 缩小淡入 |

### 4.7.4 缓动函数

道具飞入动画使用 `Curves.easeOutCubic` 变换：

```dart
final curvedT = Curves.easeOutCubic.transform(t);
position = _from + (_to - _from) * curvedT;
```

## 4.8 地图与场景实现

### 4.8.1 背景

游戏使用单张 GIF 动态背景（`SpaceBackground.gif`），通过 `ParallaxComponent` 或直接作为游戏组件的底层 Sprite 渲染。

### 4.8.2 坐标系设计

项目采用 Flame 默认坐标系（原点 = 左上角，Y 轴向下）：

```
y=0         → 屏幕顶部（敌人出生点）
y=size.y    → 屏幕底部（炮塔位置）
炮塔 Y       → size.y * 0.92
射击范围     → y > size.y * (1 - rangePercent)
```

### 4.8.3 屏幕适配

所有尺寸使用 `size` 属性相对计算：
- 敌人生成 X 随机范围：`size.x * 0.12` ~ `size.x * 0.88`
- 敌人停止线：`size.y * 0.5`
- 炮塔位置：`size.y * 0.92`

竖屏锁定：`SystemChrome.setPreferredOrientations([DeviceOrientation.portraitUp])`

## 4.9 分数、生命值与游戏规则实现

### 4.9.1 生命值系统

```dart
void _onEnemyReachedBottom(Enemy enemy) {
  // 先检查护盾
  if (_buffManager!.consumeShield()) {
    // 护盾吸收伤害，敌人被摧毁，不掉血
    enemy.removeFromParent();
    return;
  }

  final dmg = (enemy is JingLeiEnemy && enemy.isDrainPhaseComplete) ? 10 : 5;
  _hp -= dmg;
  if (_hp <= 0) {
    _hp = 0;
    _gameOver = true;
  }
}
```

### 4.9.2 经验与击杀

```dart
void _onEnemyKilled(Enemy enemy) {
  if (enemy.isBattery) {
    // 电池：无经验，不计击杀，只播放特效
    add(DeathExplosion(position: enemy.position));
    enemy.removeFromParent();
    return;
  }

  _addExp(enemy.expValue); // 10 或 30
  _killCount++;
  add(DeathExplosion(position: enemy.position));

  // 精英击杀处理
  if (enemy is EliteTrait) {
    _tryDropItem(enemy.position); // 12% 道具掉落
  }
}
```

### 4.9.3 Buff 选择流程

1. `_triggerLevelUp()` → 设置 `_buffState = 1`，`_paused = true`
2. `BuffCardOverlay` Widget 检测到 `_buffState == 1`，显示卡片
3. 玩家点击卡片 → `game.selectBuff(buffId)` → `BuffManager.addLevel(buffId)`
4. `_paused = false`，游戏继续

## 4.10 游戏界面实现

### 4.10.1 Flutter 与 Flame 的混合架构

游戏主场景（`GameScreen`）使用 **Stack 布局**混合 Flutter Widget 和 Flame 渲染：

```
Stack(
  children: [
    GameWidget(game: _game),            // Flame 游戏画布
    Positioned(top: 0, ...) HUD(...),  // HP/EXP/波次信息
    Positioned(left: 0, ...) ItemBar(...), // 道具栏
    if (_showCards) BuffCardOverlay(...),  // Buff 选择卡片
    if (_showBanner) AcquiredBanner(...),  // 道具获取横幅
  ],
)
```

### 4.10.2 HUD 通信机制

// 游戏端：每帧更新

}

// Flutter 端：60fps 轮询
_timer = Timer.periodic(const Duration(milliseconds: 16), (_) {

## 4.11 音频实现

### 4.11.1 背景音乐管理

使用 `audioplayers` 包实现 BGM 播放：

```dart
class AudioManager {
  static final AudioManager instance = AudioManager._();
  AudioPlayer? _player;
  String? _currentPath;

  Future<void> playBgm(String assetPath, {bool loop = true, double volume = 0.60}) async {
    if (_currentPath == assetPath) return; // 去重
    await _player?.stop();
    _player = AudioPlayer();
    await _player!.play(AssetSource(assetPath));
    if (loop) _player!.setReleaseMode(ReleaseMode.loop);
    _currentPath = assetPath;
  }
}
```

## 4.12 数据存储实现

### 4.12.1 存储方案选择

使用 `shared_preferences` 轻量级键值存储，满足天赋系统和星级评价的持久化需求。

### 4.12.2 TalentManager 实现

```dart
class TalentManager {
  static final TalentManager instance = TalentManager._();
  late SharedPreferences _prefs;

  Future<void> init() async {
    _prefs = await SharedPreferences.getInstance();
    _availablePoints = _prefs.getInt('talent_points') ?? 0;
    // 加载已解锁天赋
    final unlocked = _prefs.getStringList('unlocked_talents') ?? [];
    _unlocked = unlocked.map((e) => TalentId.values.byName(e)).toSet();
  }

  int getStarsForLevel(int levelId) => _prefs.getInt('star_$levelId') ?? 0;

  void setStarsForLevel(int levelId, int newStars) {
    final oldStars = getStarsForLevel(levelId);
    if (newStars > oldStars) {
      _availablePoints += (newStars - oldStars); // 差额奖励
      _prefs.setInt('star_$levelId', newStars);
      _save();
    }
  }

  bool unlock(TalentId id) {
    if (_availablePoints <= 0 || _unlocked.contains(id)) return false;
    _availablePoints--;
    _unlocked.add(id);
    _save();
    return true;
  }
}
```

### 4.12.3 异常恢复

读取数据时提供默认值，确保首次运行不崩溃：
- 天赋点数默认 0
- 星级默认 0
- 首次运行时给予 1 个免费天赋点

## 4.13 游戏暂停、继续和重新开始

### 4.13.1 暂停机制

```dart
// Buff 选择时暂停
void _triggerLevelUp() {
  _paused = true; // 冻结游戏循环
  _buffState = 1; // 通知 UI 显示卡片
}

// update 方法中
@override
void update(double dt) {
  if (_paused) {
    super.update(0); // dt=0 冻结所有子组件
    return;
  }
  super.update(dt);
  // ...正常游戏逻辑
}
```

### 4.13.2 继续游戏

玩家选择 Buff 后：`_paused = false; _buffState = 0;` → 游戏恢复正常更新。

### 4.13.3 重新开始

重新开始通过**重新创建 GameWidget**实现：

```dart
void _restartGame() {
  setState(() {
    _game = DefendTheTowerGame(background: widget.background);
  });
}
```

旧游戏对象及其所有子组件随着 Dart 垃圾回收自动释放。

### 4.13.4 避免重复对象

- 重新开始时创建全新的 `DefendTheTowerGame` 实例
- `onLoad()` 中重新初始化所有组件
- `TalentManager.startGame()` 重置每局状态（Buff 级别、重抽次数）

## 4.14 异常处理与优化

### 4.14.1 资源预加载

所有大型精灵表在 `onLoad()` 中预加载并缓存为 `static List<Sprite>`，避免游戏中实时 I/O：

```dart
// EMP 冲击波、闪电链、雷击、死亡爆炸、命中闪光、火焰风暴
await Future.wait([
  EmpWave.preload(),
  LightningChain.preload(),
  LightningStrike.preload(),
  DeathExplosion.preload(),
  HitFlash.preload(),
  FireStorm.preload(),
]);
```

### 4.14.2 对象生命周期管理

- 子弹超时 3s 自动 `removeFromParent()`
- 状态效果计时归零自动 `removeFromParent()`
- 特效动画播放完毕自动 `removeFromParent()`
- 敌人越界（`y > size.y + 10`）自动移除
- 闪避残影最多 3 个，超出后旧的被移除

### 4.14.3 避免每帧重复创建对象

- 伤害数字、命中特效等短生命周期对象使用构造函数创建，用完即弃（Dart 的垃圾回收对小对象高效）
- 精灵和纹理使用 `static` 缓存，所有实例共享同一份资源
- `Damagenumber` 的 `TextPainter` 在构造函数中创建，不在 `render()` 中重复创建

### 4.14.4 子弹和敌人数量控制

- 子弹最大生命周期 3s，避免无限飞行累积
- 波次生成基于计时器，不会同时刷出大量敌人
- 震荡波可摧毁子弹，减少活跃子弹数量

### 4.14.5 资源加载失败处理

- 音频播放失败：`try-catch` 静默降级，不影响游戏运行
- 图片加载失败：Flame 引擎抛出异常，在开发阶段修复

### 4.14.6 防止快速点击

- Buff 选择后立即设置 `_buffState = 0`，卡片消失
- 道具使用后立即从 `_items` 移除
- 轨道打击进入瞄准模式后 `_paused = true`，点击确认后 `_exitAimingMode()`

### 4.14.7 内存管理

- 组件从树中移除时，Flame 引擎自动级联移除所有子组件（如状态效果）
- `onRemove()` 中取消定时器和回调
- `DrainLink` 等引用型组件在 `update()` 中检查目标存活状态，目标死亡时自移除
